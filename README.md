A tiny stack virtual machine in one TypeScript file: runs every i001–i040 bytecode program per ISA v1 — wrapping 32-bit arithmetic, a 256-value stack, calls, 256 words of memory, input/output, and all ten traps with their exact exit codes — and writes each program's output bytes and exit code.
